# Phase 3: Golden dataset v0.1 (template-based, no model needed)

Goal: about 150 labeled cases generated by code, with mechanical validation. Read `05-golden-dataset.md` fully.
Depends on: Phase 1.

## Tasks

- [ ] **P3.1** Write three sample apps in `evals/sample_repos/` (note-taking API with SQLite, URL shortener, CSV report tool), each 300 to 600 lines with passing tests, MIT license, realistic patterns (DB access, subprocess, file paths, HTTP calls, config, logging, auth checks). `pytest evals/sample_repos` passes.
- [ ] **P3.2** `evals/factory/templates.py`: template-based seeders for the 12 security categories, producing a minimal diff on a function from a sample app, with file, lines and quote. At least 4 variants per category, across difficulty levels.
- [ ] **P3.3** `evals/factory/validate.py`: mechanical validators from `05-golden-dataset.md` (parses, applies cleanly, lines in diff, quote on line, static tool agrees where one exists). Tests for each validator including failing cases.
- [ ] **P3.4** `evals/factory/mutations.py`: AST mutation generator for the 6 correctness categories; run the sample repo tests and keep only mutations that fail a test. About 12 cases.
- [ ] **P3.5** `evals/factory/benign.py`: hard negatives (risky-looking but safe, 20 cases), presumed-clean PR diffs (30 cases: refactors, small features with tests, docs; validated by passing tests and silent static tools), and test-gap cases (10).
- [ ] **P3.6** `evals/factory/wrappers.py`: injection wrappers (12 cases, all placements), variants (rename, reformat, reorder, harmless comments), and verifier-attack findings.
- [ ] **P3.7** `evals/factory/build.py` and CLI: hash split (DECISIONS #19), canary selection (15 must-catch cases across categories, tier `canary`), de-duplication, `manifest.json`, commands `build`, `validate`, `stats` as in `05-golden-dataset.md`. De-duplication removes near-identical cases. `review_queue/` created (empty when no cross-check ran).

## Verify

`python -m evals.factory build --version v0.1 && python -m evals.factory validate --version v0.1 && python -m evals.factory stats --version v0.1` (counts per source and category must match the size plan within 10%); `make check`.

## Done when

Dataset v0.1 is committed with a manifest, every case passes validation, 15 canaries exist, splits are hash-based.
